① 파일 불러오기

파일을 선택하면 자동으로 음성 분석을 시작해요. 첫 다운로드는 오래 걸릴 수 있어요.

📺 또는 유튜브 영상 열기

유튜브는 재생 및 시간별 문장 이동용입니다. 휴대폰 HTML에서는 링크만으로 영상 음성을 자동 추출할 수 없어요. 오류 153 시 원본 열기를 이용하세요.
링크를 열면 연결된 서버에서 유튜브 자막을 자동 확인합니다. MP3/MP4는 휴대폰만으로 분석합니다. 유튜브 자막 자동 가져오기는 별도 서버가 있을 때만 시도합니다.
⚙ 자막 서버 연결 (Netlify를 사용하는 경우)

Render에 배포한 Shadow Flow 서버 주소를 입력하세요. 예: https://my-shadow-flow.onrender.com. Render 자체 주소에서 접속했다면 비워 두세요.

자막을 가져오지 못했나요? 스크립트 붙여넣기

유튜브의 스크립트 표시에서 시간·문장 텍스트를 복사해 넣으면 자동으로 카드로 변환합니다. 예: 0:03 Hello everyone.

시간표시가 있는 스크립트는 영상과 동기화합니다. 시간표시가 없는 원문은 글자를 보존해 문장 카드로만 보여줍니다(정확한 재생 위치는 알 수 없음).

② 자동 자막 분석 상태 · 파일을 선택하면 자동 시작

🎙 내 목소리로 따라 말하기

마이크 권한 확인 전 · 파일 직접 열기에서는 녹음이 차단될 수 있어요.
🎤 쉐도잉 분석

녹음이 끝나면 길이, 쉼, 리듬 변화와 함께 현재 문장 기준 원어민/내 녹음을 비교해요. 주황색은 원어민, 초록색은 내 녹음 표시예요. 억양은 휴대폰 브라우저에서 추정한 강세/리듬 기반 시각화이므로 참고용입니다.

아직 분석한 녹음이 없어요.
주황 = 원어민 억양·쉼    초록 = 내 녹음 억양·쉼
아직 비교할 녹음이 없어요.

마이크 녹음은 HTTPS 보안 연결이 필요한 브라우저가 많습니다. `content://`나 `file://`로 직접 연 경우 제한될 수 있습니다.

자막 수정 / 직접 입력

한 줄에 시작초 | 종료초 | 영어 | 한국어(선택) 형식으로 적고 불러올 수 있습니다.

개인 학습용 · 자막 자동 인식은 인터넷을 통해 모델을 내려받지만 음성 자체는 휴대폰에서 처리하도록 설계되었습니다. 무료 번역은 외부 서비스로 문장 텍스트를 전송할 수 있습니다.
