Shadow Flow V19 Android 앱 프로젝트

이 파일은 설치 가능한 APK가 아니라 Android Studio 프로젝트입니다.

1. Android Studio에서 ShadowFlowAndroid 폴더를 엽니다.
2. Gradle 동기화가 완료되면 Build > Build Bundle(s) / APK(s) > Build APK(s)를 선택합니다.
3. app/build/outputs/apk/debug/app-debug.apk를 갤럭시에 설치합니다.

기능: MP3/MP4, 휴대폰 Whisper 전사(기기 성능에 좌우됨), 영어/한국어 Drill, 문장 저장/복습, 휴대폰 마이크 녹음, 음성 강세/쉼 비교, 스크립트 붙여넣기.

유튜브 링크에서 ChatGPT의 질문하기 기능을 자동 호출하거나 ChatGPT 채팅 내용을 직접 읽지는 못합니다. ChatGPT가 출력한 원문을 복사하여 앱의 스크립트 입력란에 붙여넣으세요.
시간표시 없는 원문은 글자 누락을 막기 위해 전체를 한 카드로 보존하므로 구간 동기화는 불가능합니다.
시간이 있는 SRT/VTT 또는 유튜브 타임스탬프가 포함된 대본은 해당 구간 재생 가능.
원어민/내 녹음 표시의 색상은 음량 기반 강세와 쉼의 근사치이지 정확한 음높이나 발음점수가 아닙니다.
YouTube 자막 자동 다운로드는 유효한 백엔드를 배포/연결하지 않는 한 지원되지 않습니다.
